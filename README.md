## Usage

### Visit

You could visit [a deployed website at Vercel](https://kuzminklk.vercel.app/)

### Use

1. Clone the codebase via `git clone https://github.com/kuzminklk/personal-website`
2. Install dependencies by `pnpm install`
3. Run development project via `pnpm dev`
